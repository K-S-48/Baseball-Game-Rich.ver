## ⑤工夫した点・こだわった点
- 実際にボールを表示させ、動くようにした点。

- ％での位置調整にしたことでデザイン崩れはなくなったが、まだまだ検証ツール等使い切れていなくて、実際に画面サイズを変更しながらチェックしているつもりでも、なぜか縮小、拡大しているだけで確認したいことが確認できなかったこと。原因は、pxからの変更忘れの部分があったことでした。
- もうちょっと自分で考えてコードを書く努力をしたいです。
